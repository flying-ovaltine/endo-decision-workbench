# 内分泌临床决策专家团 · DSH 插件

[English](README.en.md) | 中文

给一线内分泌科医生的决策工作台：**先排危险、再排概率**。它不是问答框，是一张能直接拿去做决定的桌子——录完病例，鉴别清单按「可能性 × 漏诊后果」双轴排好，每行都必须有反证，命中急诊红线就立刻中断。

## 装了之后有什么

| 装了什么 | 内容 |
|---|---|
| **左侧边栏面板** `内分泌决策` | 病例录入、六个工作流、角色点条、鉴别清单、检查路径、诊疗计划、六档证据标记 |
| **技能** `endocrinology-decision-team` | 主任医师「问渠」式判断口径：九条铁律、六档证据、三档输出、查证据四步 |
| 一键 | 「复制病例简报」把结构化事实包 + 规则要求放进剪贴板，粘进对话即可 |

## 面板里有什么

1. **病例录入**：主诉与时间轴 / 关键阳性 / 关键阴性（已排除方向）/ 已用药物 / 已有检查（数值 + 单位 + 检测方法）。
2. **六个工作流**：门诊速决 · 疑难鉴别 · 方案制定 · 进展速递 · 病例复盘 · 跨科共管。切换工作流会点亮**实际参与的那几位**角色（八位里只亮需要的，简单问题不亮满八个）。
3. **鉴别清单**：六列（诊断 / 支持点 / **不支持点** / 可能性 / 漏诊后果 / 排除方法）。默认**双轴排序**，也可按单轴排；**「不支持点」留空的行会标红并计入「无效输出」**——这是硬校验，不是提示。
4. **检查路径**：一行一个节点，用「若 A 阳性 → …」写分叉；没做的检查写「未评估」，不当阴性用。
5. **诊疗计划**：目标值 / 药物 / 剂量区间 / 监测时点 / **六档证据标记**（指南强推荐、指南弱推荐、RCT、单臂Ⅱ期、机制推测、推断）。
6. **急诊红线**：命中糖尿病急性并发症、严重低血糖、甲状腺危象、黏液性水肿昏迷、肾上腺危象、垂体卒中、严重低钠、高钙危象、TED 视神经病变、甲状腺结节压迫任一项，面板**只留一条红色横幅**，其余内容收起，只让你去拿"现在做什么 / 送哪里 / 不要做什么"三句话。

面板底部固定写着：**最终决策与签字由主管医师负责**。

## 用起来是什么流程

1. 左侧边栏打开「内分泌决策」，把病例填进去。
2. 选工作流，编鉴别表（记得每行都写反证）。
3. 点右上角 **复制病例简报** → 粘到对话里发送。
4. 对话按 `endocrinology-decision-team` 的规则给你报告；需要留档就把结论贴回面板。

面板负责录入、排序与校验；医学判断由技能约束下的回答给出。

## 安装

```sh
dsh plugin --profile web add "https://github.com/flying-ovaltine/endo-decision-workbench/releases/latest/download/dsh-endo-decision-team.tgz"
```

或在 **插件 → 插件市场** 搜「内分泌」。

```sh
pnpm install && pnpm build && node --test test/smoke.mjs
```

## 边界（写死在插件里）

- **不做最终诊断、不开处方**，只给分析与路径。
- 引用只到「指南全名 + 版次」或「期刊名 + 年份」，不确定写「版次待核」；不编 DOI、样本量、OR/HR。
- 未做的检查一律「未评估」，不当阴性结果用。
- 仅用于临床决策训练与辅助，不构成医疗建议。
